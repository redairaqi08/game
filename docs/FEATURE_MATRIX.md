# Couverture du cahier des charges — jalon 0.1

Cette matrice confronte le cahier des charges intégral aux sources du jalon. Elle distingue une fonctionnalité présente dans le code d'une exigence validée en jeu. **Implémenté** signifie qu'un chemin de code concret existe ; cela ne signifie ni équilibré, ni finalisé, ni validé par un essai humain. Les résultats effectivement exécutés sont consignés dans `TEST_REPORT.md`.

La demande complète correspond à une production plus large que ce jalon. Le nom de version et l'existence d'un exécutable ne suffisent pas à la déclarer achevée.

## Priorités de suite

1. Corriger toute régression de ping, occlusion, extraction, dégâts, navigation et sauvegarde révélée par les tests ; conserver une partie jouable à chaque commit.
2. Tester humainement les scènes clés au casque et en vidéo : duel acoustique, diversion, poursuite piégée, extraction couverte, interception proche.
3. Évaluer humainement le tutoriel guidé et la préparation de manche ; ajouter une salle pédagogique dédiée et les contrôles libres d’entraînement.
4. Produire une vraie route verticale avec collisions, navigation et perception multiétage, puis évaluer son effet sur l'équilibre.
5. Finaliser paramètres réellement appliqués, accessibilité, mesures GPU/CPU et art/animations/son, puis engager des séries d'équilibrage documentées.

Les scores d'une simulation, même réussie, ne valident ni le plaisir de jeu ni la qualité artistique finale.
