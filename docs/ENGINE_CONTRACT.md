# SONAR engineering contract — Godot 4.6

Native desktop game, compatibility renderer. Coordinates: Y up, meters. World collision layer 1, actors 2, gadgets 4. Source assets procedural and authored, no external dependencies. Root `scripts/game.gd` owns match and scene. Agents own only assigned files; communicate changes.

## Root SonarGame (Node3D)
Properties: `actors: Array`, `human` (actor/null), `level`, `acoustics`, `gadgets`, `audio`, `ui`, `bots: Array`, `phase: String` (`menu`, `playing`, `between`, `finished`), `settings: Dictionary`, `elapsed: float`, `time_left: float`, `round_index: int` (0 based), `attacker_team: int`, `scores: Array` [int,int], `extraction_alerts: Dictionary` exit_id->remaining seconds. Settings keys: team_size (1/2/3), difficulty (0..3), rounds (4/6), mode (`standard`, `attack`, `defend`, `training`, `tutorial`, `simulation`), primary_gadget/secondary_gadget strings, mouse_sensitivity, volume, fov, camera_motion, graphics.
Methods: `start_match(options: Dictionary)`, `next_round()`, `return_to_menu()`, `set_paused(value: bool)`, `notify(message: String, team: int = -1)`, `on_actor_died(victim, killer)`, `on_actor_hit(shooter, victim, damage: float, headshot: bool)`, `command_allies(order: String)`, `active_exits() -> Array`, `get_observer()` (human or spectated ally).
Root invokes bot `tick(delta)` each physics frame while playing. Actor checks phase. Extraction handled by root using actor.command_interact and exits. Round rebuild destroys all actors/effects/gadgets and resets contact memories.

## SonarActor (`scripts/actor.gd`, CharacterBody3D)
`setup(game_ref, actor_id: int, team_id: int, human_controlled: bool, spawn: Vector3)` after add_child. Fields `game`, `actor_id`, `team`, `is_human`, `alive`, `extracted`, `health`, `ammo`, `reserve`, `weapon_index`, `reload_left`, `ping_cooldown`, `camera: Camera3D`, `visual: Node3D`, `aim_direction: Vector3`, `command_interact: bool`, `extraction_progress: float`, `stats: Dictionary` (`kills`,`damage`,`pings`,`gadgets`,`extractions`), `gadget_loadout: Array`, `gadget_used: Array`, `stance: String`.
Methods: `apply_command(command: Dictionary)` keys `move` Vector3 world horizontal normalized, `look` Vector3 world normalized, `fire`, `aim`, `sprint`, `crouch`, `jump`, `reload`, `ping`, `interact`, `gadget` slot int -1 default. `take_damage(amount: float, source, headshot: bool=false)`, `eye_position() -> Vector3`, `set_reconstruction(confidence: float)` (visual only; allies solid, enemies acoustic shader), `set_spectating(value: bool)` if useful. Human input inside actor, only while mouse captured/playing and !paused. Shooting ray mask7, actor2, headshot by hit height. Acoustic emissions for actions and movement; ping and gadgets via services.

## SonarAcoustics (`scripts/acoustics.gd`, Node)
`setup(game_ref)`, `emit_sound(source, category: String, origin: Vector3 = Vector3.INF, overrides: Dictionary = {})`, `ping(source) -> bool`, `contact_for(observer, target_id: int) -> Dictionary`, `contacts_for(observer) -> Array`, `clear()`, `has_line_of_sight(from: Vector3, to: Vector3, exclude: Array = []) -> bool`. Records fields `target_id`, `position` estimated LAST known only, `confidence` 0..1, `state` 0..4, `age`, `category`, `confirmed` bool, `team` if known. Same perceptual pipeline for all. Never exact silhouette through opaque world. Bots must not inspect true enemy locations; can use records then look up id only when confirmed and LOS verified. Visual reconstruction controlled by acoustics for observer. Acoustics ticks itself only when playing. VFX via own nodes in world, depth tested. Audio `game.audio.play_event(category, origin, intensity=1.0)`.

## SonarGadgets (`scripts/gadgets.gd`, Node3D)
`setup(game_ref)`, `deploy(actor, slot: int) -> bool`, `clear()`, `jam_factor(position: Vector3, observer_team: int) -> float`. Types `decoy`, `veil`, `thorn` attack / `ear`, `bell`, `choir` defend. Actor.gadget_loadout chosen in root based role. One per slot per round, actor.gadget_used. Destructible layer4. Same emit_sound for decoys, never flag fake to bots.

## SonarLevel (`scripts/level.gd`, Node3D)
`build(team_size: int = 3)`, `spawns: Dictionary` keys `attack`,`defend` -> Array Vector3, `exits: Array` dicts `{id: String,name: String,position: Vector3,radius: float,duration: float}`, `nav_bounds: Rect2`, `nav_obstacles: Array[Rect2]` (XZ inflated by actor radius by AI), `zones: Array` dict `{name,position: Vector3}`, `cover_points: Array` Vector3, `world_size: Vector2`, `get_zone(position: Vector3) -> String`. 3v3 full map, 1v1 and2v2 tightened geometry and exits. Geometry navigable on floor Y0 (ramps/upper routes optional). Wide connecting passages and three meaningfully different routes. Root owns environment/camera menu; level owns lighting, scenery, collision, gate effects. Optional `set_exit_active(id, active)`.

## SonarBot (`scripts/bot.gd`, RefCounted) / navigation
`setup(game_ref, actor_ref, index: int)`, `tick(delta: float)`, `set_order(order: String, position: Vector3 = Vector3.ZERO)`. Fields `state: String`, `goal: Vector3`, `last_path: PackedVector3Array`, `stuck_count: int`. AI can inspect allies/objectives, not true enemies unless contact verified. Difficulty delays + spread only. Alert exit id maps objective location not target. Root initializes shared `navigation` (`scripts/navigation.gd`, RefCounted) with `setup(level)`; method `find_path(from,to) -> PackedVector3Array`, `is_walkable(position) -> bool`.

## SonarUI (`scripts/ui.gd`, CanvasLayer)
`setup(game_ref)`, `show_menu()`, `show_round_result(summary: Dictionary)`, `show_final_result(summary: Dictionary)`, `push_message(text: String)`, `set_pause(value: bool)`. UI observes root state each process. Options start by game.start_match. Menus/settings persisted root user://. `summary` fields title, subtitle, scores, round, rounds, extracted, stopped. In match HUD HP/ammo/ping/gadgets/team/time/progress, map using known contacts only, orders UI. Root will call ui methods. Layout reference 1600x900 stretch canvas_items. Main menu can show level background. French UI, English source identifiers.

## SonarAudio (`scripts/audio.gd`, Node)
`setup(game_ref)`, `play_event(category: String, origin: Vector3, intensity: float=1.0)`, `set_volume(value: float)`. Generate original WAV assets offline, spatial AudioStreamPlayer3D bounded voices. Ambient/music subdued. Headless no audio exceptions.

Use `var x: Type = ...` when inference comes from Variant to avoid Godot parse warnings. Avoid global class loading cycles: preload scripts with constant names or dynamic root references. Keep API stable. No commits by subagents; root commits and pushes.
